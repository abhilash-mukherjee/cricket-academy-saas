# Batch editing lives on the Batch page

`/app/batches` is a directory: Batch name, whether it is open or closed for Registration, and the offered fee options as read-only facts. Rename, open or close for Registration, and fee-option changes happen on `/app/batches/[batchId]`, above the Batch roster. That URL used to be the roster alone. Putting the forms back on the directory, or giving setup its own third URL, were the other shapes. The directory was one wall of actions. A third URL would split one Batch into a list, a roster, and a setup screen.

**Considered options:** Restyle the directory and leave every control on it (rejected — the confusion is how many jobs one screen holds). A separate setup screen linked from the roster (rejected — rename, fee options, and the roster are one Batch).
