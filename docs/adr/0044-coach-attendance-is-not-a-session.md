# Coach attendance is not a Session

Player attendance is a Session: one Batch on one calendar date, present marked explicitly, everyone else absent when the list is saved, and discard removes that list. Coach attendance is a different record: one Coach, one Batch, one calendar date, today or in the past, explicitly present or absent. No Session is required, including when the Batch is closed or has no Players. A day with no mark is neither present nor absent. Marking the same Coach, Batch, and date again replaces the mark; clearing it removes it. Discarding a Session leaves Coach attendance in place. A month for one Coach and one Batch is the present dates, the absent dates, and those two counts. Hanging the mark off a Session would block any day that has no Player Session, and would turn an untouched Coach into an absence the way an unmarked Player does. Coaches are not coupled to a Batch, so there is no fixed list to save.

**Considered options:** Require a Session for that Batch and date (rejected — the Owner can mark a Coach when no Players were listed); one saved list of every Coach for a Batch-day, with unmarked meaning absent (rejected — absence is only an explicit mark, and Coaches are not assigned to Batches).
