# Academy images live in Vercel Blob

Brochure gallery photos, Coach profile photos, and the conversion-page UPI QR are uploaded by the Owner through authenticated server routes; files land in Vercel Blob as public objects under academy-scoped keys (`academies/{academyId}/…`), and Postgres stores the key only (ADR-0026). Upload-only — no external URL paste. Max file size, allowed formats, and gallery count caps live in `lib/constants.ts` and are enforced on the upload API. Blobs are deleted when a saved image is removed or replaced; picks that never get saved may orphan until a later sweeper. Vercel Blob fits managed infra (ADR-0003) and Vercel hosting (ADR-0004) without self-hosted object storage. Considered: Cloudflare R2 / S3 (more setup for a solo operator), client-side direct upload (rejected — auth and validation stay on the server).
