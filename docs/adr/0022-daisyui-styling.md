# DaisyUI is the styling kit

The Next.js UI is Tailwind CSS plus DaisyUI: semantic components and one product theme for staff/product chrome (`/app/…`, `/login`, `/`). On public Academy pages (`/a/{academy-slug}` and `/a/{academy-slug}/join`), the Owner chooses between DaisyUI `dark` (default) and `light` surface modes plus one brand accent colour from a curated swatch list (`default`, `emerald`, `blue`, `crimson`, `amber`, `violet`, `teal`, `orange`) applied to primary actions and selection highlights — not raw DaisyUI token pickers (`secondary`, `accent`, `neutral`, etc.) that would require design micro-management or risk unreadable contrast. shadcn/ui or a CSS-in-JS kit would also work, but DaisyUI matches utility-first Tailwind on Vercel without a second component ownership model. Phone-first layout is ADR 0023, not a breakpoint footnote.
